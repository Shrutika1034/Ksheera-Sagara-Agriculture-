# Ksheera-Sagara Dairy Management App

Ksheera-Sagara is an Android-based dairy farm management application developed using Kotlin and Room Database.

## Features

- Income Management
- Expense Tracking
- Profit/Loss Analytics
- Dashboard with Charts
- PDF Report Generation
- Dark/Light Theme Support
- Search Functionality
- Room Database Persistence

## Technologies Used

- Kotlin
- Android Studio
- Room Database
- MPAndroidChart
- Material UI Components
- RecyclerView
- ViewBinding
